# Hazel PR Company Website

React website built with Vite and React Router.

## Pages

- `/` - Home
- `/about` - About Us
- `/services` - Services
- `/hazel-security` - Hazel Security
- `/clients` - Our Clients
- `/contact` - Contact Us

## Getting started

1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev` to start the development server.
4. Run `npm run build` to create a production build.

Page copy and visual styling are placeholders until the approved design and client requirements are available.
